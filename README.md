# Крипто-облік

Сайт для обліку обміну **гривень на USDT**: скільки гривень ти передав (готівкою або на карту), скільки USDT тобі кинули, який курс був у кожній операції і хто кому скільки винен.

## Можливості

- **Акаунти.** Реєстрація через email і пароль, вхід з будь-якого пристрою.
- **Спільні книги обліку.** Створюєш книгу, ділишся посиланням-запрошенням, і всі учасники бачать та додають операції. Видно, хто що записав. Кожен може мати кілька книг (особисту й спільні).
- **Автоматичний курс.** Вводиш будь-які два числа (гривні, USDT або курс), і третє рахується саме. Наприклад: «мені кинули 680 USDT, це 28 560 ₴» → курс 42,00. Показує, наскільки курс відрізняється від звичайного курсу людини.
- **Баланс з кожною людиною.** Видно, хто кому винен у USDT і скільки це приблизно в гривнях. Кнопка «Записати повернення боргу» підставляє залишок у форму.
- **Підсумки.** Скільки всього передано гривень, отримано USDT, середній курс. Фільтр за місяцем або довільним періодом.
- **Експорт у CSV** (відкривається в Excel).
- Світла й темна тема, працює з телефона.

## Як влаштовано

- Чистий HTML/CSS/JS без збірки. Сайт розміщено на GitHub Pages.
- Дані зберігаються в [Supabase](https://supabase.com) (Postgres). Доступ обмежено правилами Row Level Security: користувач бачить лише ті книги, в яких він учасник.
- Схема бази: [`supabase/schema.sql`](supabase/schema.sql).

| Файл | Що в ньому |
|---|---|
| `index.html` | Розмітка сторінки |
| `css/style.css` | Стилі |
| `js/app.js` | Логіка застосунку |
| `js/config.js` | Адреса проєкту Supabase і публічний ключ |
| `supabase/schema.sql` | Таблиці, функції та правила доступу |

## Розгорнути свою копію

1. Створи проєкт у Supabase і виконай `supabase/schema.sql` у SQL Editor.
2. Впиши URL проєкту і publishable-ключ у `js/config.js`.
3. У Supabase → Authentication → URL Configuration вкажи **Site URL** = адреса твого сайту (наприклад, `https://<логін>.github.io/crypto-oblik/`) і додай її в **Redirect URLs**.
4. Увімкни GitHub Pages для гілки `main` (Settings → Pages).

Publishable-ключ не є секретом: його можна викладати у відкритий код, бо дані захищені правилами RLS.
